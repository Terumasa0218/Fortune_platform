# 鑑定文スタイルガイド

## 目的

計算根拠の詳しさを保ちながら、読者が自分のこととして無理なく読める文章へ変える。
専門用語は鑑定根拠へ残し、無料鑑定の本文では日常の行動や場面へ翻訳する。

## 調査から得た共通点

- 最初に短いタイプ名や一文の結論を置き、自分の輪郭をすぐにつかませる。
- 強みだけでなく、同じ性質が弱みへ変わる場面も対にして示す。
- 抽象的な資質の名前より、日常で起きる行動や感情を先に書く。
- 一段落には一つの話題だけを置き、長い説明は小見出しで分ける。
- 「当たっている」で終わらせず、結果をどう使うかまで案内する。
- 専門用語を消すのではなく、読みたい人だけが根拠タブで確認できるようにする。
- ユーモアは断定や茶化しではなく、読者が自分を少し笑って受け止められる程度にする。

## 無料鑑定の基本構成

1. ひとことで言うと: 一文で才能の核を伝える。
2. 自分ごとになる説明: 日常の疑問、反応、行動から説明する。
3. もう一つの強み: 別の計算要素を、重複しない役割として伝える。
4. 活きやすい場面: 具体的な場面を二つまで示す。
5. 伸ばす鍵: 今日から試せる行動を一つ示す。

無料部分だけでも才能そのものは理解できるようにする。職業名、詳細な環境、弱みが強く出る条件、時期の分析は詳しい鑑定へ分ける。

## 3つの文体

### すっきり

短く明確で、初めて読む人にも意味がぶれない。公開版の基準候補。

### 寄り添い

読者の内面にある迷いや経験を一度受け止めてから、強みとして言い直す。柔らかいが、過度に励まさない。

### 軽いユーモア

日常の小さな「あるある」を一つ入れる。比喩は一段落に一つまでとし、鑑定結果を冗談にしない。
